# Introduction

Completed

* 10 minutes

This module explains the mobile experiences for finance and operations apps. Additionally, it explains how to plan and build apps by using Microsoft Power Platform.

The mobile platform helps make it easier for you to change the forms and mobile app definitions to include customizations that you've made to finance and operations apps. You can build mobile apps by using Microsoft Power Platform, which will help you provide rich offline and mobile interactions and a user-friendly designer experience.

Important

You need to have the following components set up before you can begin working with mobile experiences:

* Microsoft Power Platform integration enabled and connected to a new or existing Microsoft Power Platform environment. For more information, see [Enable Power Platform Integration](/en-us/dynamics365/fin-ops-core/dev-itpro/power-platform/enable-power-platform-integration?azure-portal=true#licensing-and-capacity-considerations).
* Appropriate licensing and capacity space.

We recommend that you understand integration concepts for finance and operations apps before completing this module. For more information, see [Integrate finance and operations apps with Microsoft Power Platform](/en-us/training/paths/integrate-finance-operations-apps-power-platform/?azure-portal=true).
