# Virtual entities

Completed

* 10 minutes

Finance and operations apps are virtual data sources in Microsoft Dataverse. You can use these data sources to allow create, read, update, and delete (CRUD) operations from Dataverse and Microsoft Power Platform. Before you can complete CRUD operations on finance and operations apps entities from Dataverse, you need to make the entities available as virtual entities in Dataverse.

You must make sure that virtual entities exist in your finance and operations apps instance for the data that's needed for your mobile experience. Several virtual tables are available with the application, but you might need to create more virtual entities. Virtual entities are important components of building mobile experiences because they help the application fetch the appropriate data from finance and operations apps. As a result, the apps can function properly.

To work with virtual entities, you need to have **Power Platform Integration** enabled and set up. This feature provides a seamless integration between Dataverse and finance and operations apps in a bidirectional flow with near real-time, service-to-service call. You can view the integration details in the Power Platform admin center and Microsoft Dynamics 365 Lifecycle Services.
