# Introduction

Completed

* 8 minutes

In this module, you learn about the built-in reporting capabilities of finance and operations apps. You also explore the integration capabilities of finance and operations apps with other Microsoft products, such as Microsoft Power Platform, Excel, Outlook, and Word.

For example, a financial analyst at a large organization needs to prepare a monthly financial report. The analyst generates accurate financial statements by using the built-in reporting capabilities of finance and operations apps. These reports use Power BI to create interactive dashboards for deeper trend analysis and better insights.

Through Microsoft 365 integration, the analyst shares findings using Excel and schedules review meetings through Outlook. Business events automate notifications for purchase order confirmation, while configurable business documents support electronic reporting requirements. Additionally, Finance and Supply Chain Management insights enable forecasting of future performance and detection of anomalies, ensuring decisions are informed and proactive.

## Learning objectives

By the end of this module, you're able to:

* Describe built-in reporting capabilities.
* Describe options for analyzing data by using Power BI.
* Describe Microsoft 365 integration capabilities.
* Describe integration capabilities with Microsoft Power Platform.
* Describe use cases and capabilities for business events.
* Describe configurable business documents, including Electronic reporting.
* Describe how Finance insights supports forecasting and anomaly detection.

Learn about the reporting and integration features that are shared across the finance and operations apps.
