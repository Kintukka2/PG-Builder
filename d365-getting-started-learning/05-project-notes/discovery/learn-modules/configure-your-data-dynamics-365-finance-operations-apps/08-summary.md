# Summary

Completed

* 1 minute

In Finance and Operations apps, forms are only the tip of the iceberg when it
comes to updating data.

You can update in Microsoft Excel; you can use Word to add files to product
masters; you can email notifications from Outlook. Security differs by role and
affects the data that you see. New entities can be created for integration in or
out, and recurring data transfers can easily be set up.
