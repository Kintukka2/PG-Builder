# Assign roles

Completed

* 3 minutes

System administrators and users who are assigned to the Feature manager role or the Feature viewer role can open the **Feature management** workspace. These two roles were created to support the Feature management experience. Users who have the Feature manager role can turn on or off any feature. Additionally, they can update the **Comments** field for the feature. Users who have the Feature viewer role can only view the **Feature management** workspace; they can't turn on or off any features.

The Feature manager role and Feature viewer role don't override the existing security that a user has. People with these roles control whether the user can turn on and off features, but they don't provide access to the features.
