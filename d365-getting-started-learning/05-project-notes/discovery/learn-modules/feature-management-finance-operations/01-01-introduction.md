# Introduction

Completed

* 1 minute

Feature Management protects users from potential disruptions caused by new functionalities after an update. Features are added and updated in every release. The Feature management experience provides a workspace where you can view a list of features that have been delivered in each release. Then, you can use the workspace to view feature documentation and to enable or disable certain features that fit your organization best.

You receive notifications about recommended features. You can then review the features and request activation from your administrator. Administrators are notified and can evaluate whether the feature aligns with the organization’s needs before enabling it.

In this module, you will learn how to use the **Feature management** workspace.
