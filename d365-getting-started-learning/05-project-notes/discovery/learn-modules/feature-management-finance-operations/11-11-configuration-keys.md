# Features that use configuration keys

Completed

* 2 minutes

If a feature uses a configuration key, but the configuration key isn't turned on, the **Feature management** workspace doesn't show the feature in the list of available features. After you turn on the configuration key, you need to update the feature list by using the **Check for update** menu item. Then, the feature will appear in the feature list.

If you turn off the configuration key, the feature will not be removed from the feature list.
