# Disable a feature

Completed

* 3 minutes

If a feature has been enabled, the **Disable** button will appear in the details pane. You can use this button to disable the feature. The **Disable** button isn't available if the feature can't be disabled.

After a feature is disabled, it can be re-enabled. Features that haven't been enabled will appear on the **Not enabled** tab.
