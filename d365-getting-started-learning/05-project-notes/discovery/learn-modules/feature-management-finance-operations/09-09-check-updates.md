# Check for updates

Completed

* 1 minute

Features are added to your environment after each update. However, you can manually check for updates by selecting the **Check for updates** button. Features that were added to the system after the update will be added to the list of features. For example, if a flighted feature is enabled after a release, then you can check for updates and the feature will be added to your list.
