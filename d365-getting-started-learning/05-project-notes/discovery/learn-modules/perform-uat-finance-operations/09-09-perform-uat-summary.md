# Summary

Completed

* 2 minutes

In this module, you learned how to build test cases to test business
functionality without the need for development skills.

The main purpose of user acceptance testing (UAT) is to verify that
specific business scenarios work as you would expect.

The goal is to help you catch issues or errors before you go
to the production environment without needing a developer to code for you.
