# Summary

Completed

* 3 minutes

This module discussed the concept of financial dimensions, which are subaccounts to general accounts that you can use for detailed reporting and analysis. It outlined the benefits of using financial dimensions and explained the types:

* **Custom dimensions** - Are user-defined and shared across legal entities.
* **Entity-backed dimensions** - Have values that you define elsewhere in the system.

Also, the module covered the process of creating and managing financial dimensions and values, including activation, deletion, and setting overrides for legal entities. You were also introduced to features like default dimension values and derived dimensions, which automate dimension assignment based on predefined rules.

The module also explained how to set up financial dimension templates and sets for distributing source document amounts and for reporting purposes. Advanced topics include defining account structures and advanced rules, which organize main accounts and financial dimensions for accurate tracking and reporting.
