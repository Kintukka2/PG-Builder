# Introduction

Completed

* 3 minutes

This module introduces the concept of financial dimensions in Dynamics 365 Finance. Financial dimensions are subaccounts to general accounts, providing a detailed breakdown for reporting and analysis. They simplify the accounting process by allowing detailed analysis without creating a detailed chart of accounts.

Imagine you are a financial analyst in a multinational corporation. Your company uses Dynamics 365 Finance for its financial management. You are tasked with creating financial dimensions to help analyze, classify, and organize financial transactions according to voucher and account number. You also need to set up account structures, which define valid combinations for a chart of accounts. These structures determine the sequence for journal entry and allow flexibility in the number of financial dimensions for different accounts. Your goal is to optimize your organization's business operations by improving financial management and reporting procedures.
