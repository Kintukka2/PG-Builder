# Summary

Completed

* 2 minutes

In this module, you have learned how to use Microsoft Office integration in finance and operations, configure email (SMTP/Exchange), and to create and maintain email templates to standardize the messages when sending emails to customers.

By setting up network printing features, you can use corporate network printers remotely. Finally, this module provided an overview of how to integrate data from multiple sources into Microsoft Dataverse for Apps.
