# How to use View and Edit modes

Completed

* 5 minutes

The View and Edit modes indicate whether you're editing or viewing a record. This distinction is important, because it helps prevent accidental updates to data in the finance and operations apps.

The View and Edit modes on specific pages can be used for different purposes:

* **View mode** - To review data on a list page, review data in a record, or open related records by using the links on pages.
* **Edit mode** - To change data directly on the page that you're viewing. You can also use links to open related records, as you can in View mode.
