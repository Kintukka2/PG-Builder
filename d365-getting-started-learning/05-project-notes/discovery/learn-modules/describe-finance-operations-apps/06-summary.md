# Summary

Completed

* 6 minutes

This module provides a comprehensive overview of finance and operations apps, including:

* **Dynamics 365 Finance** – Manages financials, budgeting, and accounting processes.
* **Dynamics 365 Supply Chain Management** – Optimizes supply chain operations, inventory, and logistics.
* **Dynamics 365 Commerce** – Supports retail and e-commerce operations.
* **Dynamics 365 Human Resources** – Handles employee management, payroll, and HR processes.
* **Dynamics 365 Project Operations** – Facilitates project management, resource allocation, and project accounting.

It explains how these applications support global financial systems, simplify operations, and enhance decision-making through real-time insights and AI-powered tools like Microsoft Copilot. The module covers key concepts such as enterprise resource planning (ERP), use cases for AI integration, and the user interface elements that improve usability and productivity. It also highlights security features, workflow automation, reporting capabilities, and integration with Microsoft tools like Microsoft Power Platform, Outlook, and Excel.

Learners gain a foundational understanding of how finance and operations apps can transform business processes and improve operational efficiency after completing this module.

Now that you reviewed this module, you should be able to:

* Describe enterprise resource planning (ERP).
* Describe use cases for using AI tools in finance and operations apps, including Copilot and agent capabilities.
* Navigate efficiently within and across finance and operations apps.
