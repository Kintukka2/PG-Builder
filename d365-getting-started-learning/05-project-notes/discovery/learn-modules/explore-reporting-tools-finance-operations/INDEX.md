# Explore reporting tools in finance and operations apps

Source: https://learn.microsoft.com/en-us/training/modules/explore-reporting-tools-finance-operations/

Summary: A report is a structured presentation of data. Reporting presents data in a way that lets you make informed decisions by using data visualizations, dashboards, financial reporting, and structured documents. finance and operations apps provide several reporting tools that you can use to meet different reporting needs. This module will help you become familiar with the various reporting options that are available with finance and operations apps.
