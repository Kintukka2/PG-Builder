# Customize help topics

Completed

## Task guides

Your admin team can help you create custom task guides for your environment. It can also invest in connecting a custom Help site for your environment, if your business needs require it.

## Field descriptions

You can customize field descriptions if, for example, you want to add company-specific information. You can also add descriptions for additional fields. For more information, see [Customize field descriptions](/en-us/dynamics365/fin-ops-core/dev-itpro/user-interface/customize-field-help/?azure-portal=true).
