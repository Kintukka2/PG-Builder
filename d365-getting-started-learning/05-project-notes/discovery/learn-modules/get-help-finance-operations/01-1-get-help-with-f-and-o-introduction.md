# Introduction

Completed

* 2 minutes

Learn how to get help and find out more about finance and operations apps, as well as protecting the privacy and personal data of your customers.

You can get training and help for finance and operations apps from official websites like [Microsoft Learn documentation](/en-us/dynamics365/fin-ops-core/fin-ops/?azure-portal=true) and [Microsoft Learn training](/en-us/training/?azure-portal=true). Additionally, from inside the apps, you can find context-sensitive help in Microsoft Learn documentation and in task guides that are stored in a library in [Lifecycle Services](https://lcs.dynamics.com/?azure-portal=true).
