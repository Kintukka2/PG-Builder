# Set up batch jobs in finance and operations apps

Source: https://learn.microsoft.com/en-us/training/modules/setup-batch-jobs-finance-operations/

Summary: By using batch jobs, you can avoid slowing down your computer or the server during typical working hours. You can run many tasks in finance and operations apps as part of batch jobs. For example, batch jobs can include tasks for printing reports, performing maintenance, or sending electronic documents.
