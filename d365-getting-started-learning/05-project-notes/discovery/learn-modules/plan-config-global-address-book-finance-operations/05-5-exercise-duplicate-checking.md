# Exercise - Add a new record and check for duplicates

Completed

* 16 minutes

## Scenario

As an IT manager in **USMF**, you need to add a new record **Desert Wholesales** into the global address book. Also, you need to add a new contact for **Cave Wholesales** named Aaron Painter.

The purpose of these exercises is to establish a connection between a new contact and a customer record. With this new record created, there is a duplicate check that can be run to ensure there are no repeating records.

## Prerequisite

First you need to create an address book for this lab.

1. In **USMF**, go to **Organization administration** > **Global address book** > **Address books**.
2. Select **New**.
3. In the **Name** field, enter **Desert WS**
4. In the **Description** field, enter **Desert Wholesales**.
5. Select **Save**.

## Add a new record to the global address book

1. Go to **Common** > **Common** > **Global address book**.
2. Filter to locate your recently added record titled **Desert Wholesales** in the Address books drop-down menu on the page.
3. Click **New** in the Action Pane.
4. In the **Name** field, enter **Desert Wholesales**.
5. In the **Address books** drop-down list, select **Desert WS**.
6. Select **Select**.
7. Expand the **Addresses** FastTab and select **Add**.
8. In the **Name or description** field, enter **Desert Wholesales Group**.
9. In the **Zip/postal code** field, enter **89005**.
10. Select **OK**.
11. In the Action Pane, select the **Party** tab, then in the **Maintain** group, select **Check for duplicates**.
12. Set the values for **Name** and **Zip/postal code** to **yes**.
13. Select **Search**.
14. Note the duplicate found.
15. Set the **Email** value to **yes**.
16. Select **Search**.
17. Note the message that **No duplicates found**.
18. Because no email was entered on the added record and you searched for an email match, no duplicate was found. You must only search to match records you have entered.
19. Select **OK**.
20. Close the page.

## Add a contact to customer record

1. Select **Accounts receivable > Customers > All customers**.
2. Select **Cave Wholesales, US-004**.
3. Select **Customer > Accounts > Contacts > Add contacts**.
4. For first name, enter **Aaron**, for last name, enter **Painter**.
5. Note the popup form with the previous record.
6. Select **Use match**.
7. Select **Save**.
8. Close all the pages.
