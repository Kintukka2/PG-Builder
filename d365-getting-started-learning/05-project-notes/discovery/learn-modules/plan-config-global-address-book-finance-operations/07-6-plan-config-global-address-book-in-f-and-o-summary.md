# Summary

Completed

* 2 minutes

You’ve learned what the global address book is, how it works, and how to plan for the global address book and other address books.

You also learned that the global address book is a centralized repository for master data that must be stored for all internal and external persons and organizations that the company interacts with. When an address changes, the update must be made in only one place. All the other associated records are updated automatically.

For more information about the global address book, see [Address books FAQ](/en-us/dynamics365/fin-ops-core/fin-ops/organization-administration/qa-address-books?azure-portal=true&toc=/dynamics365/finance/toc.json).
