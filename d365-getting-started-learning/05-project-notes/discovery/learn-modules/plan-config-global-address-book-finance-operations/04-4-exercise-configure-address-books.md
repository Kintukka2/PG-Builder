# Exercise - Configure address books

Completed

* 16 minutes

## Scenario

As an IT manager in **USMF**, you need to create an address book and describe the party records for each retail store location. You also need to create a new party and associate the party with an address book. Finally, you need to use this party to create a prospect.

You create a new record in the address book and add this information to a newly created prospect. This exercise demonstrates the relationship between people and organizations and how this set up takes place.

1. Go to **Organization administration** > **Global address book** > **Address books**.
2. Select **New**.
3. In the **Name** field, enter **Denver**.
4. In the **Description** field, enter **Denver Store**.
5. Select **Save**.
6. In the **Available Teams** list, find and select the **Safety team**.
7. Select the right arrow to add the **Selected Teams**.
8. Select **Save**.
9. Go to **Common** > **Common** > **Global address book**.
10. Select **New**.
11. In the **Type** field, select **Person**.
12. In the **First name** field, enter your first name.
13. In the **Last name** field, enter your last name.
14. In the **Address books** field, select **Denver**.
15. Select **Select**
16. Select **Save**.
17. Under the **Party** tab in the **New** section, select **Prospect** to view the new prospect information.
18. Close all pages.
