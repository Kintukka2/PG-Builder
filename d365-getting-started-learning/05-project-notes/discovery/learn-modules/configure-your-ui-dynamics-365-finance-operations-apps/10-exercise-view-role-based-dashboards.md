# Exercise – View role-based dashboards

Completed

* 5 minutes

Users are assigned dashboards according to their roles. If a user has need of an
additional dashboard, this is easily done.

1. Navigate to **System administration** module, **Security**, **Assign users
   to roles**.

![Modules, System administration, Security, Assign users to roles](media/10-m2-l10-p1.png)

2. Select the **Accounting manager** role and notice a person who is in it –
   Oscar, in the demo data.

![Accounting manager has user Oscar assigned to the role](media/10-m2-l10-p2.png)

3. Highlight Oscar or your selected person, and at the top, you may select
   Options, Personalize, Add to workspace.
4. Select the desired workspace from the drop-down and how it’s presented
   (tile, list, or link).

![Options, Personalize, Add to workspace](media/10-m2-l10-p3.png)
