# Introduction

Completed

* 6 minutes

Finance and operations apps provide a comprehensive set of shared features that work consistently across all modules. These capabilities include security, workflows, batch processing, document management, alerts, number sequences, organizational structures, and the global address book. Understanding these foundational elements helps ensure consistency, compliance, and operational efficiency within your organization.

Standardized features across finance and operations apps ensure seamless integration and consistency. Organizations working in complex environments particularly benefit from this unified approach, which streamlines business processes, improves compliance, reduces duplicated effort, and increases operational efficiency.

## Learning objectives

In this module, you learn how to:

* Describe security capabilities of finance and operations apps.
* Describe workflow capabilities of finance and operations apps.
* Describe the concept of batch jobs.
* Describe organization and legal entities.
* Create and maintain record templates.
* Describe global address book features and their use cases.
* Describe alerts.
* Describe number sequences.
* Describe attachment capabilities.
